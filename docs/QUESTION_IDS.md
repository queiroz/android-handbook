# Stable question IDs

Question IDs are permanent public identifiers. Slugs may describe the topic, but IDs support cross-references even if wording changes.

## Rules

- Use uppercase prefixes and three-digit numbers, for example `COR-014`.
- Never reuse an ID after publication.
- Do not renumber published questions to make a sequence visually tidy.
- Related-question metadata contains stable IDs, not slugs.
- Module introductions do not need IDs.
- New prefixes require a documented curriculum decision.
